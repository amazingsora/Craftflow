查 `generation_history` 的 SQL（`backend\craftflow.db`）：

```sql
SELECT id, datetime(created_at) AS utc_time, workflow,
       json_extract(params,'$.prompt_profile') AS profile,
       json_extract(params,'$.mechanism')      AS mech,
       json_extract(params,'$.lllite_strength') AS lllite,
       json_extract(params,'$.img2img_denoise') AS i2i,
       json_extract(params,'$.cn_weight')       AS cn_w
FROM generation_history ORDER BY id DESC LIMIT 10;
```

⚠️ `created_at` 存 **UTC**，台北時間要 **+8**。
